# v2研究准备与执行计划

日期：2026-10-02。对应完整中英文v2方案。设计文件已建立；人工校准、PRESS、注册及正式检索未完成。

## 研究价值与交付标准

面向Frontiers in Immunology的中心问题是：运动后候选免疫标志物，在哪些时间、人群和测量情境下，已获得支持个体化解释的证据，哪些环节仍缺少验证。全文围绕免疫测量及其验证链展开，训练负荷和恢复表现作为情境/协变量。讨论必须区分细胞重新分布、实测功能与感染结局，不以组学规模替代生物学或临床验证。

完成品包括：可复现五库与补充检索、可审计双人筛选、独立队列关联的数据集、设计适配评价、三类证据图、同行评审证据和预印本分表、PRISMA-ScR及PRISMA-S清单、投稿稿件及公开方法附件。范围综述方法不因投稿类别名为Systematic Review而改变。

## 阶段与启动条件

| 阶段 | 预计准备工日/时长 | 必须形成的材料 | 完成后才进入下一阶段的条件 |
|---|---|---|---|
| 1. 策略与工具准备 | 3–5个工作日，可并行 | 确认Embase平台；五库翻译；PRESS记录；文献管理/筛选工具配置；当前JBI表单归档 | 平台能解析、主题词核实、修订闭环、日志可导出 |
| 2. 人工校准 | 5–7个工作日，依可用时间调整 | 冻结草案题录池；保存种子的50篇随机试筛；全文边界练习；10篇目的性试提取 | 原始一致率≥80%且概念分歧解决；字典可填；两人能区分时间、样本单位和验证类型 |
| 3. 方案冻结与注册 | 2–3个工作日 | 同步中英文及手册；人员/资金/COI；OSF注册内容；公开探索与试点披露 | 人类团队确认最终方案并实际完成注册；登记实际时间与ID |
| 4. 正式检索与去重 | 试点后估计 | 五库原始导出、校验值、去重映射、补充搜索与前沿登记 | 所有数据来源及去重计数可核对；已明确完整筛选集合 |
| 5. 双人筛选 | 按真实条目/全文量估计 | 独立判断、共识、全文位置、排除理由、检得情况、cohort关联初稿 | 无未解释冲突；未检得/待分类明确列出；PRISMA计数相符 |
| 6. 提取与评价 | 按试提取的每报告时间估计 | 双人关键字段、原文定位、评价表、独立队列关系 | 抽查追溯通过；无细胞当样本或重复队列计数；NR/NA/UNCLEAR分开 |
| 7. 综合与写作 | 阶段6后安排 | 三类地图、主表、叙述综合、局限性、相邻综述对照 | 每个结论可追溯；无预设“精准有效/感染预测”结论 |
| 8. 更新与投稿 | 投稿前安排 | 更新检索、状态/撤稿检查、清单、最终栏目/APC/声明核对 | 尽量在投稿前30日内更新；所有新题录走相同流程；团队批准投稿 |

准备阶段合计约2–3个工作周，为规划估计。工作日可并行但双人独立判断不可省略；此表不承诺整个综述在三周内完成。

## 工作量计算方法

试筛记录两位评审各自用于50条初筛、全文与分歧解决的有效工时；试提取分别记录常规检测、组学报告的用时。用实际正式题录数和预估全文比例推算：初筛人时=题录数×单人每条分钟×2/60；全文人时=待评全文数×单人每篇分钟×2/60。提取与评价按研究类型分层估计，同一队列多报告共享信息可减少重复但仍需核对。另列检索、获取、去重、仲裁和更新工时；设置团队自定余量，不把未知命中数代入计算。

若正式数据量超出资源，先重新分配时间和人员；确需改范围时，在筛选/结果选择前形成有理由的修订并追溯重筛。不得按显著性、方向、发表期刊或期望结论删减。

## 近期优先顺序

1. 团队填写`project_settings.json`中的人员、Embase平台、软件和声明；复核研究边界。
2. 检索负责人打开五库草案，完成主题词和语法核查，邀请独立PRESS复核；所有反馈写入日志。
3. 形成并保留草案检索池，用50篇随机试筛和10篇目的性试提取检验可执行性。试点不等于正式完成。
4. 将实际试点及本次公开证据侦察披露进注册草稿，修订版本后由团队提交OSF。
5. 按注册后策略运行正式检索，从原始导出开始保留完整证据链。

当前无需重新讨论是否保留运动后/精准监测方向；已按用户认可方向更新。尚缺行政事实应如实待填，不影响团队先读方案、校准和核对平台。
