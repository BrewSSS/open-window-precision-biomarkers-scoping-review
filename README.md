## 本次设计确定了什么

- **核心A：** 可识别急性运动/比赛，至少一个运动后免疫测量，并有运动前基线或合适对照。保留即刻采样，不设30分钟下限或72小时上限。
- **支持B：** 同一人在至少两次具体运动后重复测同一免疫指标，采样与运动时序明确，并有基线/合适对照；单独呈现，与A按cohort ID去重。
- **精准监测七个域：** 分析可靠性、时间有效性、免疫特异性、个体化、功能/临床关联、独立验证及使用验证、可行性。分别描述，不合成为分数。
- **候选发现与验证分开：** 群体变化、直接功能、临床关联、未来预测及独立验证分别编码；阴性和冲突结果保留。
- **检索：** 五库从建库起至实际执行日，不设语言限制；运动×免疫与运动×组学两路并集。策略仍待实际平台验证和PRESS复核。
- **人工流程：** 两位研究者独立全量筛选与关键字段提取；50篇随机试筛、10篇有目的试提取；无AI自动排除。
- **计数：** 独立队列为主要证据密度单位；报告数、样本数、细胞数、特征数分别记录。预印本另表、另分母。
