### Merge of batches 237–242 + 032 into ta_ai_merged.csv (2026-10-09)

`scripts/ta_ai_merge.py --ai-b out_B --ai-c out_C --ai-opus out_O --master records_master.csv --stage1 ai_stage1/ti_ai_merged.csv --out-dir ai_stage2 --age-rule-defer` (same flags as the batch-236 merge; the literal historical command line for batch 236 was not found verbatim in the repo or git log, so this invocation was reconstructed from the script's argparse definition — it reproduces the batch-236 `ta_ai_summary.json`'s `seed=20261005`/`sample_frac=0.10` exactly, so the reconstruction is treated as confirmed). `ta_ai_merged.csv`/`ta_ai_summary.json` were backed up to `/tmp/ta_screen2/before_merge/` before running.

**Regression check** (every one of the pre-existing 9,277 records, comparing backup vs new `ta_ai_merged.csv`): `ai_final`, `ai_final_code` and `adjustment` are byte-identical for every record **except** those legitimately superseded by a later batch file sharing the same `record_id` (364 records tagged `RESCREENED_BATCH_{237..242}`/`RESCREENED_BATCH_032` — the same supersession mechanism already used for batches 235/236; these are records from the stage-2 `SAMPLE_VERIFY` population that a human had already advanced by hand before PRE-007, now independently re-confirmed by the new AI passes). 0 unexplained changes to `ai_final`/`ai_final_code`/`adjustment` on any non-superseded record.

`review_scope`, however, changed for **739 of the 9,277 pre-existing records (8.0%) that were NOT touched by this run at all** (370 `SAMPLE_VERIFY`→`AI_EXCLUDE_UNVERIFIED`, 369 `AI_EXCLUDE_UNVERIFIED`→`SAMPLE_VERIFY`). Cause: the seeded 10% human-verification sample is drawn with `random.Random(20261005).sample(excl, k)` over `excl` = every agreed, non-conflict `EXCLUDE_TA` record **sorted by `record_id` across the whole stage-2 population**. Adding 1,061 new records (many of which are themselves agreed exclusions, interspersed by `record_id` throughout the id range, not appended at the end) changes both the length and the order of `excl`, so the same seed draws a different 10%-of-a-different-population — this reshuffles which *old* records fall in the sample even though their own AI/human data never changed. This is a structural property of `ta_ai_merge.py`'s sampling (not a bug introduced here) that any future pool-growing merge will reproduce; it is reported here rather than worked around, per instruction. Net effect size is small (`SAMPLE_VERIFY` 465→519, consistent with the larger exclusion pool) but reviewers should be aware that workbook `sample_verify` sheet membership for previously-reviewed-but-not-yet-locked records can move between runs.

New totals: `ai_final` ADVANCE 4,393 / EXCLUDE_TA 5,521 / AWAITING 2; `review_scope` FULLTEXT_CANDIDATE 4,393 / AI_EXCLUDE_UNVERIFIED 5,002 / SAMPLE_VERIFY 519 / AWAITING 2.
